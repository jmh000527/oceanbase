Core Features Implemented
================================================================================

1. SQL Normalization Engine
   - Parse tree traversal and analysis
   - Constant extraction and replacement
   - Signature generation with MD5 hashing
   - Support for multiple data types

2. Outline Storage System
   - Database schema with two tables
   - Three-level hash table cache
   - Efficient lookup by signature/SQL ID/name
   - Statistics tracking

3. Multi-Strategy Matching
   - Four matching strategies with priority
   - Signature-based matching
   - SQL ID-based matching
   - Format outline support

4. Hint Application
   - Hint parsing and validation
   - Integration layer for pg_hint_plan
   - Planner hook integration
   - Query modification

5. Management Interface
   - 7 SQL management functions
   - Create, alter, drop, enable operations
   - Import/export functionality
   - List and query operations

6. Monitoring and Statistics
   - Usage count tracking
   - Performance metrics
   - Cache hit/miss ratios
   - Management views

Build Instructions
================================================================================

1. Navigate to plugin directory:
   cd /home/runner/work/oceanbase/oceanbase/pg_outline_plugin

2. Build the extension:
   make clean
   make

3. Install the extension (requires superuser):
   sudo make install

4. Enable in PostgreSQL:
   psql -d your_database -c "CREATE EXTENSION pg_outline;"

5. Configure (optional):
   Edit postgresql.conf:
     shared_preload_libraries = 'pg_outline'
     pg_outline.enabled = on
     pg_outline.cache_size = 1000

6. Restart PostgreSQL:
   sudo systemctl restart postgresql

       '/*+ SeqScan(pg_class) */'

   -- Verify
   SELECT * FROM pg_outline_info;

3. Check logs for initialization:
   tail -f /var/log/postgresql/postgresql-*.log
